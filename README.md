# ashulab

Ashu Lab's Claude Code plugin marketplace - opinionated skill sets for real
engineering work, not vibe coding.

## Install

```
/plugin marketplace add AshuLab/skills
/plugin install solve@ashulab
```

## Plugins

| Plugin | What it's for |
|---|---|
| **[solve](./solve)** | Idea -> shipped, in phases with clear boundaries: `sharpen -> to-spec -> to-tickets -> ship`, plus `pushback` to stress-test thinking on its own, `tdd` / `code-review` as discipline tools, `research` / `prototype` to feed the thinking, and `diagnose` as an on-ramp for bugs. |

See each plugin's README for its design principles and skill map.
